# MCU Watchlist

An unofficial, fan-made Marvel Cinematic Universe watchlist in release order, from Phase 1 through the latest releases and announced upcoming projects.

## Live site

[Open the MCU Watchlist](https://turjobarai.github.io/mcu-watchlist/)

## Features

- Browse entries by MCU phase.
- Search titles and filter by format or phase.
- Track watched titles and view your progress.
- Browse announced, dated, and TBA projects separately.
- Use the responsive dark interface on desktop or mobile.

Watch progress is saved in the current browser using local storage. It does not sync between browsers or devices.

## Run locally

Open `index.html` in a modern web browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a repository and upload `index.html` to its root on the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.
5. GitHub Pages will show the published site URL in the Pages settings.
